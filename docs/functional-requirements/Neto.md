## Requisitos Funcionais

| id | requisito | prioridade |
| --- | --- | --- |
| RF-001 | O sistema deve permitir a consulta de lugares, estabelecimentos, eventos e experiências disponíveis na região do Cariri. |  |
| RF-002 | O sistema deve centralizar informações sobre lugares, estabelecimentos, eventos e experiências em uma única plataforma. |  |
| RF-003 | O sistema deve exibir informações detalhadas e relevantes dos locais cadastrados, como nome, descrição, cidade, categoria, tipo de experiência, ambiente e características do espaço. |  |
| RF-004 | O sistema deve informar o horário de funcionamento dos locais cadastrados. |  |
| RF-005 | O sistema deve informar a localização dos locais cadastrados. |  |
| RF-006 | O sistema deve fornecer instruções de como chegar aos locais cadastrados. |  |
| RF-007 | O sistema deve divulgar locais, estabelecimentos e eventos pouco conhecidos ou com baixa visibilidade. |  |
| RF-008 | O sistema deve auxiliar no planejamento de visitas por meio de informações organizadas, suficientes e confiáveis. |  |
| RF-009 | O sistema deve disponibilizar o cardápio dos estabelecimentos gastronômicos cadastrados, quando aplicável. |  |
| RF-010 | O sistema deve disponibilizar formas de contato dos estabelecimentos cadastrados. |  |
| RF-011 | O sistema deve disponibilizar informações básicas e confiáveis sobre eventos da região. |  |
