## Requisitos Funcionais

| id | requisito | prioridade |
| --- | --- | --- |
| RF-001 | O sistema deve permitir que o usuário visualize o cardápio e a faixa de preços de um estabelecimento. |  |
| RF-002 | O sistema deve permitir que o usuário visualize fotos do ambiente de um estabelecimento ou local. |  |
| RF-003 | O sistema deve exibir os horários de funcionamento de um estabelecimento. |  |
| RF-004 | O sistema deve exibir a localização e informações sobre o perfil do bairro ou entorno de um estabelecimento. |  |
| RF-005 | O sistema deve informar se um local possui programação musical, eventos ou outras atividades programadas. |  |
| RF-006 | O sistema deve disponibilizar um canal de contato atualizado do estabelecimento. |  |
| RF-007 | O sistema deve disponibilizar um catálogo de localidades para consulta dos usuários. |  |
| RF-008 | O sistema deve exibir uma lista de localidades populares ou muito visitadas. |  |
| RF-009 | O sistema deve permitir que o usuário visualize avaliações e comentários de pessoas que já visitaram um local. |  |
| RF-010 | O sistema deve permitir a atualização regular das informações da plataforma, incluindo eventos e novidades da região. |  |
