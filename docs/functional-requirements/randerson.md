## Requisitos Funcionais

| id | requisito | prioridade |
| --- | --- | --- |
| RF-001 | O sistema deve centralizar informações sobre atrações turísticas, culturais, gastronômicas e de lazer do Cariri em uma única plataforma. |  |
| RF-002 | O sistema deve disponibilizar informações detalhadas dos locais cadastrados. |  |
| RF-003 | O sistema deve exibir resumos objetivos sobre os locais e experiências disponíveis. |  |
| RF-004 | O sistema deve manter informações atualizadas e confiáveis sobre os locais cadastrados. |  |
| RF-005 | O sistema deve permitir a visualização de avaliações e comentários realizados por visitantes. |  |
| RF-006 | O sistema deve permitir que usuários publiquem avaliações e comentários sobre os locais visitados. |  |
| RF-007 | O sistema deve recomendar novos lugares e experiências aos usuários. |  |
| RF-008 | O sistema deve permitir a criação de listas de locais desejados e visitados. |  |
| RF-009 | O sistema deve permitir marcar locais como visitados. |  |
| RF-010 | O sistema deve disponibilizar funcionalidades de checklist para acompanhamento de experiências e passeios. |  |
