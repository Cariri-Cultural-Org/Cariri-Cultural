| **PI-RF06 / PI-HU06** | Pedro afirma que sua maior dificuldade está relacionada à divulgação dos locais e que muitos aparecem por acaso no feed das redes sociais. | O sistema deve divulgar locais pouco conhecidos ou com baixa divulgação nas redes sociais. | Como morador que descobre lugares principalmente pelas redes sociais, quero encontrar locais pouco divulgados, para não depender apenas do acaso do meu feed. |
| **PI-RF07 / PI-HU07** | Pedro diz que gostaria de uma solução que facilitasse a descoberta de locais, o acesso a informações importantes e o planejamento das visitas. | O sistema deve auxiliar no planejamento de visitas a locais da região. | Como morador que costuma conhecer novos locais, quero planejar minhas visitas com antecedência, para organizar melhor meu tempo e evitar falta de informação durante o passeio. |

| **LM-RF12 / LM-HU12** | Lucas afirma que deixa de conhecer muitos estabelecimentos comerciais e eventos da região por falta de informações. | O sistema deve divulgar estabelecimentos comerciais e eventos da região que possuem pouca visibilidade ou informações limitadas. | Como morador do Cariri, quero descobrir estabelecimentos e eventos pouco divulgados, para não deixar de conhecer experiências por falta de informação. |

# Artefato 1 — Requisitos Funcionais

**Perspectiva do sistema. O que ele deve fazer.**

| ID | Descrição | Prioridade |
|---|---|---|
| **RF-00** | O sistema deve permitir a consulta de lugares, estabelecimentos, eventos e experiências disponíveis na região do Cariri. |  |
| **RF-01** | O sistema deve centralizar informações sobre lugares, estabelecimentos, eventos e experiências em uma única plataforma. |  |
| **RF-02** | O sistema deve exibir informações detalhadas e relevantes dos locais cadastrados, como nome, descrição, cidade, categoria, tipo de experiência, ambiente e características do espaço. |  |
| **RF-03** | O sistema deve informar o horário de funcionamento dos locais cadastrados. |  |
| **RF-04** | O sistema deve informar a localização dos locais cadastrados. |  |
| **RF-05** | O sistema deve fornecer instruções de como chegar aos locais cadastrados. |  |
| **RF-06** | O sistema deve divulgar locais, estabelecimentos e eventos pouco conhecidos ou com baixa visibilidade. |  |
| **RF-07** | O sistema deve auxiliar no planejamento de visitas por meio de informações organizadas, suficientes e confiáveis. |  |
| **RF-08** | O sistema deve disponibilizar o cardápio dos estabelecimentos gastronômicos cadastrados, quando aplicável. |  |
| **RF-09** | O sistema deve disponibilizar formas de contato dos estabelecimentos cadastrados. |  |
| **RF-10** | O sistema deve disponibilizar informações básicas e confiáveis sobre eventos da região. |  |
