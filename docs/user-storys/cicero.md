# Histórias de Usuário baseadas nas entrevistas realizadas

| ID | História |
|----|----------|
| AS-HU01 | Como novo morador, quero ver avaliações detalhadas de outros usuários sobre segurança e higiene, para decidir se vale a pena visitar um local. |
| AS-HU02 | Como usuário que tem restrições de horário, quero filtrar locais por horário de funcionamento, para não me deslocar até um lugar fechado. |
| AS-HU03 | Como morador sem veículo em área com transporte precário, quero saber como chegar a cada local com opções de ônibus, corrida por app ou distância a pé, para me planejar antes de sair. |
| AS-HU04 | Como usuário que confia em recomendações pessoais, quero ver locais bem avaliados por pessoas com perfil similar ao meu, para ter a mesma confiança que teria numa indicação de um amigo. |
