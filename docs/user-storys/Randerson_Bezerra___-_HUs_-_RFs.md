# Requisitos Funcionais — Iago Conserva - IC

|ID|Descrição|
|---|---|
|IC-RF01|O sistema deve disponibilizar informações detalhadas dos locais, incluindo descrição, localização e características gerais.|
|IC-RF02|O sistema deve exibir resumos objetivos sobre os locais e eventos cadastrados.|
|IC-RF03|O sistema deve recomendar novos lugares e experiências na região.|
|IC-RF04|O sistema deve manter informações atualizadas e confiáveis sobre os locais cadastrados.|
|IC-RF05|O sistema deve permitir a visualização de avaliações e comentários realizados por visitantes.|
|IC-RF06|O sistema deve permitir a criação e gerenciamento de listas de locais visitados e desejados.|
|IC-RF07|O sistema deve permitir que usuários publiquem avaliações e comentários sobre os locais.|
|IC-RF08|O sistema deve centralizar informações turísticas, culturais e gastronômicas do Cariri em uma única plataforma.|

# Histórias de Usuário — Iago Conserva - IC

|---|---|

|IC-HU03|Como visitante, quero receber sugestões de novos lugares para conhecer opções diferentes das que costumo frequentar.|
|IC-HU04|Como usuário, quero consultar informações atualizadas para evitar frustrações durante minhas visitas.|
|IC-HU05|Como visitante, quero consultar avaliações de outros usuários para reduzir incertezas antes da visita.|
|IC-HU06|Como usuário, quero organizar os locais que já visitei e aqueles que desejo conhecer para acompanhar minhas experiências.|
|IC-HU07|Como visitante, quero compartilhar minhas avaliações para ajudar outras pessoas na escolha de destinos.|
|IC-HU08|Como usuário, quero encontrar informações em um único local para não depender de múltiplas fontes de pesquisa.|
